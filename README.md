# The Blend Investor Room

Static site for investors.fatatelier.com. Data, sign-in and private documents live in Supabase
(project gitkvycewiomelvunxbc). Every table is protected by row-level security; only emails on the
investor list can see anything.

Deploy: publish this folder as-is (GitHub Pages, Netlify or any static host). `CNAME` sets the
custom domain on GitHub Pages.
